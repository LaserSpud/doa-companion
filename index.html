Version notes
Changes made to Doa Companion

Version 1.12

  • A doa only adds to its streak after every required line counter in that doa is complete.
  • Added Resume Reading, which returns to line 1 while keeping that doa’s counters.
  • Added Restart and Read Again, which returns to line 1 and resets only that doa’s counters.
  • Streaks remain unique to each doa, and counters remain unique to each line.

Version 1.11

  • Fixed streak registration using an immediate in-memory history cache with local storage persistence.
  • Highlighted the current weekday and filled completed days.
  • Bolded the completed doa name.
  • Adjusted the reader to fit within the iPhone Safari viewport while keeping the translation button visible.

Version 1.9

  • Fixed completed doa streaks not updating on the home page.
  • Home-page streaks now refresh whenever the home page opens.
  • If today's progress is already counted, skipping to the end now shows the existing completed progress and streak instead of the line-by-line warning.

Version 1.8

  • Matched the Version notes button design to the version number display.
  • Positioned the button directly to the left with consistent spacing.

Version 1.7

  • Added a visible rounded outline around the full horizontal scroll area.
  • The draggable scroll thumb appears while dragging.
  • Added this Version notes page.

Version 1.6

  • Added a custom horizontal scroll control for the line numbers.
  • Kept the reading controls in a stable position when changing between short and long lines.

Version 1.5

  • Restored the missing After Prayer doa lines.
  • Returned the section to 17 reading lines.

Version 1.4

  • Expanded the Doa Companion reading experience and navigation.

Version 1.3

  • Added progress and completion improvements.

Version 1.2

  • Added the version number display.
  • Added more doa content and reading controls.

Version 1.1

  • Improved the layout and doa reading experience.

Version 1.0

  • Released Doa Companion.
